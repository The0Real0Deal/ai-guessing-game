# נחשו את התמונה — משחק ניחושים מבוסס בינה מלאכותית 🎨

משחק חברתי ואינטראקטיבי בזמן אמת המשלב **מסך ראשי משותף** (בטלוויזיה / לפטופ) עם **מסכים אישיים בסמארטפונים** של השחקנים.

## 🚀 איך מריצים אצלך במחשב?

1. **שכפול המאגר:**
   ```bash
   git clone https://github.com/The0Real0Deal/ai-guessing-game.git
   cd ai-guessing-game
   ```

2. **התקנת התלויות והפעלה:**
   ```bash
   npm install
   npm start
   ```

3. **פתיחת המשחק בדפדפן:**
   - **במחשב (מסך ראשי):** פתחו את `http://localhost:3000`
   - **בטלפונים של השחקנים (באותו Wi-Fi ביתי):**
     - בדקו את כתובת ה-IP של המחשב (ב-Windows הריצו `ipconfig`, ב-Mac הריצו `ipconfig getifaddr en0`).
     - כל שחקן נכנס מהסמארטפון לכתובת: `http://<IP-OF-YOUR-PC>:3000`
     - מזינים את קוד החדר בן 4 הספרות, בוחרים כינוי ומתחילים לשחק!

## 🎮 מהלך המשחק
1. **הגדרות המארח:** הזנת רשימת מילים/ביטויים, מספר סיבובים וזמן ניחוש.
2. **לובי:** מוצג קוד חדר בן 4 ספרות + קוד QR לסריקה.
3. **שלב 1 (טלפונים):** כל שחקן מקבל ביטוי סודי ייחודי, כותב Prompt ומייצר תמונה ב-AI עד שהוא מרוצה ולוחץ "מוכן".
4. **שלב 2 (המסך הראשי):** הצגת התמונות אחת אחרי השנייה עם טיימר חי, ניחושים בקול רם, וכפתור "ניחשו נכון!" שחושף את הביטוי והיוצר עם אנימציית קונפטי.
5. **סיום:** טבלת ניקוד וגלריית תמונות של כל הסיבובים.
