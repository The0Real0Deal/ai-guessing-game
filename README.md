# צייר לי חתול! 🎨 — משחק המסיבות לניחוש תמונות AI

משחק חברתי קורע מצחוק בעברית מלאה (RTL) עם **שלושה מסכים מסונכרנים בזמן אמת** ומוכנות מלאה לפריסה ב-**Vercel + Supabase Realtime**.

---

## 🖥️ שלושת המסכים במשחק

1. **לוח בקרת מארח (מסך שני פרטי — `/host` ו-`/host/:code`)**
   - בניית קטגוריות ורשימות מילים/ביטויים (כולל חבילות מסיבה מוכנות בעברית).
   - חישוב סיבובים דינמי אוטומטי: `Math.floor(totalWords / playerCount)` — כל מילה מוקצית פעם אחת בלבד בכל המשחק ללא כפילויות.
   - ניהול חי של כל סיבוב: לכל שחקן מוצגים השם, המילה הסודית שהוקצתה לו, הפרומפט המדויק שנשלח מהנייד (עם כפתור העתקה בקליק ל-Gemini), ואזור הדבקה ייעודי (`Ctrl+V`, גרירה או העלאת קובץ) עם **דחיסת תמונות אוטומטית בצד הלקוח** (WebP/JPEG).
   - כפתורי ניקוד מהירים לשלב הניחושים בקול רם — מעניקים נקודות במקביל גם ל**מנחש** וגם ל**יוצר** התמונה.
2. **מסך ראשי להקרנה (טלוויזיה / מקרן — `/screen/:code`)**
   - קוד QR גדול לסריקה מהירה + קוד חדר בן 4 ספרות ולובי שחקנים חי.
   - תצוגת הקטגוריה הנוכחית, התקדמות השחקנים, הצגת התמונות לניחוש עם טיימר חי ומסך חשיפה חגיגי.
   - טבלת ניקוד מונפשת בסיום כל סיבוב עם שינויי נקודות (`+2`, `+1`) והערות שנונות.
   - גמר גדול ודרמטי עם פודיום, פרסים הומוריסטיים, גלריית יצירות הערב וקונפטי!
3. **מסך שחקן בנייד (`/play/:code`)**
   - סריקת QR פותחת ישירות את החדר, בחירת אווטאר וכינוי.
   - צפייה במילה הסודית (כולל כפתור הסתרה מפני מציצים!) ושליחת פרומפט יצירתי למארח.

## ☁️ פריסה ב-Vercel עם Supabase Realtime (2 דקות)

האפליקציה בנויה על ארכיטקטורה Serverless מלאה (`Vite + React + TypeScript + Supabase Realtime`) ואינה דורשת שרת WebSockets קבוע.

### שלב 1: יצירת טבלאות ב-Supabase
1. פתחו פרויקט חינמי ב-[Supabase](https://supabase.com).
2. היכנסו ל-**SQL Editor** והריצו את הקובץ [`supabase/schema.sql`](./supabase/schema.sql).
   - הסקריפט יוצר 3 טבלאות מנורמלות (`game_rooms`, `game_players`, `game_submissions`) ומפעיל עליהן **Supabase Realtime**.

### שלב 2: פריסה ב-Vercel
1. חברו את המאגר ב-[Vercel](https://vercel.com) (Vercel מזהה אוטומטית את `vite` ו-`vercel.json`).
2. הגדירו את שני משתני הסביבה הבאים ב-Vercel (או דרך חיבור Supabase Marketplace ב-Vercel):
   - `NEXT_PUBLIC_SUPABASE_URL` — כתובת הפרויקט מ-Supabase
   - `NEXT_PUBLIC_SUPABASE_ANON_KEY` — מפתח ה-`anon public` מ-Supabase
3. בצעו **Deploy** — וזהו! הטלפונים, לוח המארח והמסך הראשי יסתנכרנו מיידית מכל מקום.

## 💻 הרצה מקומית ובדיקות

```bash
npm install
npm run dev
```

- בפיתוח מקומי (`npm run dev`), גם אם עדיין לא הגדרתם Supabase, המשחק מפעיל אוטומטית מצב סנכרון מקומי (`BroadcastChannel + localStorage + Vite dev sync`) כך שאפשר לבדוק מיד מספר טאבים (או מכשירים באותו Wi-Fi).
- להרצת בדיקות לוגיקת המשחק והסיבובים:
  ```bash
  npm test
  ```
- לבניית הפרודקשן:
  ```bash
  npm run build
  ```
